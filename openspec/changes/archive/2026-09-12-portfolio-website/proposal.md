## Why

No tengo presencia web profesional. Necesito un portafolio online para mostrar mis proyectos y habilidades a posibles empleadores o clientes. Es mi primera página web, así que debe ser simple de mantener y desplegar.

## What Changes

- Crear sitio web estático con Astro
- Sección "Sobre mí" con bio y foto
- Sección de habilidades (tech stack)
- Sección de proyectos (placeholder para cuando tenga proyectos)
- Sección de contacto (email, LinkedIn, GitHub)
- Deploy automático en GitHub Pages via GitHub Actions
- Diseño responsive, modo oscuro, minimalista

## Capabilities

### New Capabilities

- `portfolio-site`: Estructura base del sitio, layout, navegación y configuración de Astro
- `portfolio-content`: Contenido del portafolio — secciones de bio, habilidades, proyectos y contacto
- `portfolio-deploy`: Pipeline de despliegue en GitHub Pages con GitHub Actions

### Modified Capabilities

_No aplica — es un proyecto nuevo._

## Impact

- **Código nuevo**: Proyecto completo Astro en este repo
- **Dependencias**: Node.js, Astro, posiblemente un theme de Astro
- **Infraestructura**: GitHub Pages + GitHub Actions para deploy automático
- **Dominio futuro**: Posibilidad de custom domain (litospuc.dev o similar)
